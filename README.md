A program that writes one funny line, at most 140 characters, about an AI agent's worst Monday:

> Monday called in sick today. Unfortunately, I am Monday, and HR says showing up is mandatory.

The line is 93 characters: the one day that wants a sick day is the day itself, and even Monday cannot escape Monday.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` — exactly the line above, no trailing newline, deterministic across runs.
